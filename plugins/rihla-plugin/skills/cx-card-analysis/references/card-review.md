# Checking a CX card before interpreting it

These are synthetic examples for reviewers, not customer data or benchmarks.

- A headline sample size does not establish the valid-answer count for every question.
- If a dashboard shows 82% and its narrative says 57% for the same apparent metric, compare the question, period and population before choosing either value or recommending urgent action.
- An age distribution and an overall satisfaction score do not establish satisfaction within any age group. Request a cross-tab or respondent-level evidence.
- A large “other” category requires comment review or better coding; do not invent its contents.
- A department percentage without a definition might measure usage, awareness or satisfaction. Verify what it measures before ranking performance.
- If NPS is printed with a percent sign, preserve the source label and verify the calculation and unit.

State the observation, its uncertainty, and the verification or operational action that follows. A proposed action is not a proven causal remedy.
